# KisaTasker

안드로이드 11 이상에서 유선 전원(USB 또는 AC 어댑터)을 감지합니다. 처음 설치하면 감시가 일시정지 상태입니다.

| 조건 | 동작 |
| --- | --- |
| 유선 연결 상태가 기본 3초 유지 | 화면 켜기 → 절전 해제 → 비행기 모드 끄기 → 위치 켜기 → Wi-Fi 핫스팟 켜기 → 선택한 내비 실행 |
| 주행 모드에서 전원 차단 후 10초 미만에 전원 복구 | 종료 예약 취소, 기존 내비 화면과 안내 유지 |
| 주행 모드에서 10초 연속 전원 차단 | 네이버지도와 티맵에서 안내 종료 시도 및 앱 종료 → 앱이 켠 핫스팟 끄기 → 비행기 모드 켜기 → 위치 끄기 → 절전 켜기 → 안드로이드 홈 화면으로 전환 |

**충전 자동화 설정 → 충전 연결 시 실행할 내비**에서 티맵(기본값) 또는 네이버지도를 선택할 수 있습니다. 선택은 다음 주행 시작부터 적용됩니다. 연결 대기 시간은 1~30초로 조정할 수 있습니다. 충전을 감지하는 동안 알림에 현재 상태와 일시정지 버튼을 표시합니다. 유선 충전기를 차량과 집에서 함께 사용한다면 차에서 내린 뒤 일반 충전 시 감시를 일시정지할 수 있습니다.

## 휴대폰 설정

1. [Shizuku 안내](https://shizuku.rikka.app/guide/setup/)에 따라 Shizuku를 시작합니다. 앱에서 **Shizuku 권한 요청 → 허용**을 누릅니다. 기본 설정의 비루팅 기기는 재부팅 후 Shizuku를 다시 시작해야 할 수 있습니다.
2. **접근성 설정 열기 → 설치된 앱 → KisaTasker · 경로 종료**를 켭니다. Android가 접근성 설정을 제한하면 앱 정보 메뉴의 **제한된 설정 허용**을 확인하세요.
3. **감시 시작**을 누릅니다. 실제 주행 전 차량에서 전원 연결, 짧은 재연결, 10초 종료를 순서대로 확인합니다.

화면 잠금이 걸려 있으면 잠금을 푼 뒤 선택한 내비를 엽니다. 전원 종료 시 잠금 화면, 접근성 꺼짐 또는 지원하지 않는 경로 화면에서는 안내 종료 버튼을 확인할 수 없어 앱 종료까지만 실행합니다. 안내 종료 또는 설정 전환이 실패하면 **최근 동작**에 표시됩니다. 비행기 모드를 켜면 이동통신이 중단됩니다. 핫스팟은 삼성 등의 기존 Wi-Fi 핫스팟 이름 및 암호를 사용합니다.

종료 확인은 앱 화면과 실행 중인 안내 서비스 기준입니다. 안드로이드는 사용자가 허용한 티맵 알림 리스너를 백그라운드에 다시 연결할 수 있습니다.

## 빌드 및 업데이트

Windows에서 Python 3, Java JDK, Android SDK 플랫폼 36 및 Build Tools 36.0.0이 필요합니다. 환경에 따라 `--jdk`, `--sdk`로 경로를 지정하세요.

1. `AndroidManifest.xml`의 `versionCode`와 `versionName`을 올립니다.
2. 기존 배포와 같은 `.signing` 폴더로 아래 명령을 실행합니다. 다른 경로에 보관했다면 `--signing <경로>`를 지정합니다.
3. 소스와 생성된 `kisa_tasker.apk`, `kisa_tasker_latest.json`을 한 커밋으로 `main`에 게시합니다.

```powershell
python build.py --notes "이번 수정 사항"
```

릴리스 키(`kisa-tasker.p12`와 비밀번호 파일)는 비공개로 백업합니다. 기존 서명 인증서와 달라지면 빌드가 교체를 거부합니다. 설치된 앱은 메타데이터에서 더 높은 버전을 찾으면 업데이트를 제시합니다. APK의 SHA-256, 패키지명, 버전 및 서명을 검사한 뒤 Android 설치 화면을 엽니다.

대기 동작은 Android 없이 검증할 수 있습니다.

```powershell
javac -d build src/dev/chargepilot/app/PowerCycle.java tests/PowerCycleTest.java
java -cp build dev.chargepilot.app.PowerCycleTest
```

이 APK는 [Shizuku API 13.1.5](https://github.com/RikkaApps/Shizuku-API)의 MIT 라이선스 라이브러리를 포함합니다.
